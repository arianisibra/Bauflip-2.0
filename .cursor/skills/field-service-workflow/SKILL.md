# Field Service Workflow

Use this skill when work touches intake, projects, scheduling, appointments, quotes, purchase orders, deliveries, invoicing readiness, technician reports, or project closure.

Prefer:
- Workflow clarity over UI polish
- Status-driven behavior and ownership handoffs
- Office/admin web as the primary system of record
- Simplicity and operational reliability over abstraction
