# shadcn/ui

Use this skill when working with shadcn components, `components.json`, presets, or registry items.

Prefer:
- Existing components before custom markup
- CLI/docs-driven usage (`npx shadcn@latest ...`)
- Proper composition primitives (`Card*`, `Dialog*`, `TabsList` + `TabsTrigger`)
- Semantic tokens and variants over ad hoc styling
