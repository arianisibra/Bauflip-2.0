# Bauflip 2.0

Web-App für Field-Service (Büro/Admin + Monteur): Projekte, Termine, Rapporte, Bestellformulare. Stack: Next.js, TypeScript, Supabase, TanStack Query.

## Quick start

```bash
npm install
cp .env.example .env.local   # Supabase-Keys eintragen
npm run dev
```

Öffnen: [http://localhost:3000](http://localhost:3000)
